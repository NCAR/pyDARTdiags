# Changelog

All notable changes to pyDARTdiags will be documented in this file.

## [Unreleased]

## [0.7.0] - 2026-08-20

### Added
- `info` routine to display summary information about an `ObsSequence` (#133).
- Function to convert a `datetime` object to DART time, with tests (#134).
- Optional `dev` and `docs` dependency extras in `pyproject.toml` (#140).
- Documentation build GitHub Actions workflow (#141).

### Changed
- Updated the external forward operator example to add external FO values for all obs of type `RAW_TRACER_CONCENTRATION` (#142).
- Added `citation.cff` and a JOSS paper link to the README.
